# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting: open the repository's **Security**
tab and select **Report a vulnerability**. Include:

- the affected repository and version or commit;
- steps to reproduce the issue;
- the potential impact;
- any suggested fix.

You will receive a response as soon as possible. Please allow time for a fix
before public disclosure.

## Supported versions

Security fixes are applied to the default branch of each actively maintained
repository.
