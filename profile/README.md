# Comandô

Order-management system for creating, tracking and managing customer orders.

## Repositories

| Repository | Description |
| --- | --- |
| [comando-backend](https://github.com/comando-systems/comando-backend) | Backend for counter and table-order management, built with TypeScript and Bun |
| [comando-frontend](https://github.com/comando-systems/comando-frontend) | Expo Router frontend for Comandô (early scaffold) |

## Status

The backend is the primary implementation, covering authentication, roles,
catalog items, counter orders and table orders. The frontend is an early
scaffold under active development.
