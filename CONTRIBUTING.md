# Contributing

Thanks for taking the time to contribute.

## Before you start

- Open an issue for bugs and feature proposals so the approach can be discussed.
- Keep pull requests focused on a single change.
- Follow the existing code style and project structure.

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Make your changes and run the project's tests, lint and build steps.
3. Update documentation when behavior changes.
4. Describe what changed and why in the pull request.

## Commits

Use clear, imperative commit messages, for example `fix: handle empty response`
or `docs: document environment variables`.

## Reporting security issues

Do not open a public issue for security vulnerabilities. Follow
[SECURITY.md](./SECURITY.md).
